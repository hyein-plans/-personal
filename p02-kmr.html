at a glance
WHY · 왜 필요했나

웹 전환만 하면 메뉴 단위로 잘린 업무와 여러 화면을 오가던 방식이 그대로 남습니다.

WHAT · 무엇을 했나

화면 이식 대신 업무 흐름 재정리를 제안하고 기획을 주도했습니다.

HOW · 어떻게 했나

업무의 기준 단위를 프로젝트로 바꾸고, 실적 등록과 전표 발행을 한 화면 흐름으로 합쳤습니다.

RESULT · 결과

프로젝트 기준으로 매출·채권 정보가 이어지고, 조회와 후속 처리를 이어서 진행합니다.

01 — why

초기 범위는
“웹 전환”이었습니다.

기존 시스템은 PowerBuilder 기반의 레거시였고, 초기 범위는 이를 웹 기반 구조로 옮기는 것이었습니다. 그런데 메뉴를 그대로 옮기면 실무자가 여러 화면을 오가며 같은 일을 이어서 처리하던 방식도 그대로 남습니다.

01
업무가 메뉴 단위로 잘려 있다

하나로 이어져야 할 업무가 메뉴에 따라 나뉘어 있어, 실무자가 화면을 옮겨 다니며 처리해야 했습니다.

02
실적 등록과 전표 발행이 분리돼 있다

하나의 흐름인데도 별도의 화면과 절차로 나뉘어 있어 후속 업무로 이어가기 번거로웠습니다.

03
정보가 프로젝트로 묶이지 않는다

매출과 채권 정보를 프로젝트 기준으로 한곳에서 확인하기 어려웠습니다.

02 — what

화면 이식이 아니라
업무 흐름 재설계를 제안했습니다.

웹 전환이라는 초기 범위에서 업무 흐름 재정리를 제안하고 기획을 진행했습니다. 등록에서 끝나지 않고 조회와 집계까지 기준을 정의했습니다.

레거시 업무 분석

기존 화면과 메뉴를 검토하고 실제 업무 기준과 후속 처리 흐름을 다시 정리

업무 프로세스 재설계 제안

초기 범위를 넘어 업무 흐름 재정리를 제안하고 기획을 주도

합산 · 계산 기준 정리

기존 메뉴와의 대응 관계를 확인하고 집계 항목의 기준 정의

동작 검증 · QA

같은 화면에서 실적 등록과 전표 처리가 정상 동작하는지 오픈 이후까지 확인

03 — how

메뉴가 아니라 프로젝트를
업무의 기준 단위로 바꿨습니다.

실적을 등록한 뒤 다른 화면으로 이동해 전표를 발행하던 절차를, 프로젝트를 고른 뒤 같은 화면에서 이어서 처리하도록 다시 구성했습니다.

03.1
무엇이 바뀌었나 — 기존과 재설계 비교
같은 업무를 네 가지 기준으로 나란히 놓고 비교했습니다.
열 이름을 눌러 한쪽만 강조해 보세요
구분
업무 기준 단위메뉴프로젝트
실적 등록 · 전표 발행별도의 화면과 절차같은 화면에서 이어서 처리
매출 · 채권 정보프로젝트로 묶이지 않음프로젝트 기준으로 연결
후속 업무여러 화면을 이동하며 처리조회와 후속 처리를 이어서 진행
03.2
하나로 이어진 업무 흐름
업무의 출발점을 메뉴가 아닌 프로젝트로 바꿨습니다.
01
프로젝트 선택
업무의 기준 단위를 프로젝트로
02
실적 추가 · 수정

03
전표 전송

미수현황과 회수내역 조회로 연결
03.3
데이터 표시 기준
같은 화면에서 이어 처리하려면 값이 어떤 기준으로 보이는지가 먼저 정해져 있어야 했습니다.
정의한 표시 기준
회수된 금액회수가 완료된 금액은 채권회수내역에 노출
동일 전표번호같은 전표번호의 여러 회수금액은 합산해 표시
미수 건회수내역 리스트에서 제외하고, 해당 합계는 0으로 표시
✓입력한 값이 후속 화면에서 어떻게 보이는지를 먼저 정의해 두었기 때문에, 두 절차를 한 흐름으로 합칠 수 있었습니다.
04 — result

웹 화면 이식이 아니라
업무 구조가 바뀌었습니다.

같은 화면에서 실적 등록과 전표 처리가 정상 동작하는지 검증했고, 오픈 이후 운영·유지보수 단계까지 확인했습니다.

절차 통합

별도로 처리하던 실적 등록과 전표 발행을 같은 업무 흐름 안에서 처리하도록 통합했습니다.

정보 연결

프로젝트를 기준으로 매출·채권 정보를 연결해 조회와 후속 처리를 이어갈 수 있게 했습니다.

데이터 반영 기준

입력한 정보가 어느 화면에 어떤 기준으로 반영되는지를 정책으로 정리했습니다.

범위의 확장

단순 웹 화면 이식에서 업무 흐름과 데이터 반영 구조의 재설계로 프로젝트 범위를 넓혔습니다.

05 — output

주요 산출물

실제 작업 문서에서 가져온 화면입니다. 개인정보와 거래 데이터는 가림 처리했습니다. 이미지를 누르면 크게 볼 수 있습니다.
